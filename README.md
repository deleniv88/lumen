# LUMEN Residence — scroll tour

Interactive scroll-driven apartment selector prototype: facade → floor plan → apartment → room-by-room tour.

Static site, no build step. Deploy on Vercel with framework preset **Other** (output = repo root).

- `index.html` — the whole site (HTML, CSS, JS)
- `img/` — renders (WebP)

Renders are AI-generated placeholders; replace with the developer's real renders and update floor/apartment coordinates in `index.html`.
